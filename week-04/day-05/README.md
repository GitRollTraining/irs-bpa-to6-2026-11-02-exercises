# Week 4, day 5: Challenge 4, a second examination group's list

This is Challenge 4. Status: draft for review, updated 2026-11-24; released to learners when the course team approves it.

A made-up examination group that has never used a model asks for its own list of new returns to
open first, learned from its own past results. Decide which error costs more for this group, set
its list by that, and make the list defensible. You work in Databricks, in this folder
(`week-04/day-05/`) of your own public fork of the course repository, and submit the code and
evidence there.

1. Follow [START_HERE.md](START_HERE.md) to fork the course repository, connect your fork and try
   the ungraded check.
2. Complete the outcomes in [CHALLENGE.md](CHALLENGE.md), starting from `notebook.py`.
3. Fill in [SUBMISSION.md](SUBMISSION.md), commit your notebook and the exports in `outputs/`
   (all in your fork's `week-04/day-05/`), and check them on GitHub. Submit your fork's URL,
   `main` and final commit SHA in Classroom.

The Classroom assignment gives the opening time, deadline and submission instructions. Keep this
README as your navigation page. The task can be completed in the browser; Genie Code is
optional. The trainer may assign the [optional Codex route](OPTIONAL_TOOLS.md).

## How this builds on the week's practice

This week you named a label, set a baseline, defended features, traced a column, fitted and
recorded two candidates, counted the four cells, read a threshold from capacity, explained one
return, compared two groups' rates and chose a technique. Week 3 gave you quality checks, year
splits and the need-to-know rule. This is a new group with new returns: its column names, its
label, its capacity and its years differ from the exercises. Read this task's tables and rules
rather than copying the exercises' names or order. The task does not tell you the steps.

Complete the fork, the Git connection and the ungraded check before Challenge day if you can.
Begin the assessed task only when the trainer opens the Classroom assignment.
