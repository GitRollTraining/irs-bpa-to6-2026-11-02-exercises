# Week 4, day 3: the two candidates judged: four cells, precision and recall, a threshold from capacity

Three exercises, in order, about 15 minutes each. Each runs in the class's Databricks workspace: open your Git folder of the course, pull, and open the exercise's notebook from it. Each reads the course's shared tables, `course.returns.model_train` and `course.returns.model_valid`, and fits Tuesday's two candidates again with Tuesday's lines, so that each return of `model_valid` has a score from each; exercise 2 also records both candidates in new MLflow runs. If a table cannot be read, the notebook makes the same rows from the course's setup file and says so. The course made up every return and every value; nothing describes how the IRS selects returns.

1. [Sort ten returns into four cells, then count every examined return (we do)](exercise-01-four-cells/README.md). What you do: sort four of ten scored returns of `model_valid` into their cells at 0.5, say what the two errors mean for an examiner, then name the counts of a given table of the 200 examined returns. Where you work: the notebook `exercise-01-four-cells/exercise.ipynb`. Done when: cell 8 prints `Done:`. [Start](exercise-01-four-cells/) · [Answer](answers/exercise-01-four-cells/)
2. [Count both candidates' matrices, then precision and recall for each (we do)](exercise-02-precision-and-recall/README.md). What you do: guess, divide each candidate's counts by hand into precision and recall at 0.5, and log them with the threshold into its run. Where you work: the notebook `exercise-02-precision-and-recall/exercise.ipynb`, then the workspace's Experiments page. Done when: cell 7 prints `Done:`. [Start](exercise-02-precision-and-recall/) · [Answer](answers/exercise-02-precision-and-recall/)
3. [Say which error costs more, then read the threshold from capacity (we do)](exercise-03-threshold-from-capacity/README.md). What you do: write which error costs more and why, read the threshold from a capacity of 25, and decide, by that sentence, whether to accept that list or ask for more capacity. Where you work: the notebook `exercise-03-threshold-from-capacity/exercise.ipynb`. Done when: cell 7 prints `Done:`. [Start](exercise-03-threshold-from-capacity/) · [Answer](answers/exercise-03-threshold-from-capacity/)

For the trainer: each answer folder's `commands.sh` runs the exercise's check on a computer with no Databricks.
