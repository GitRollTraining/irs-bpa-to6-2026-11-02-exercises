# Week 2, day 3: code review, and a return's XML

Three exercises, in order, and an extra one for anyone who finishes early. Exercise 1 works on Tuesday's made-up payment job, in a team repository of its own. Exercises 2 to 4 work on one made-up sample return, written as XML: exercise 3 starts where exercise 2 leaves off, and exercise 4 starts from exercise 3's reader. Each exercise builds its own `lab` folder, a Git repository of its own: run its reset command first, as its step 1 says.

From the course folder (containing `pyproject.toml`), run `git pull`, then `uv sync`: it adds lxml to the course's `.venv`. Select the course folder's `.venv/bin/python` as the notebook kernel, and run `source .venv/bin/activate` in each new terminal before starting Codex. Full instructions: [Set up for week 2](../../README.md#set-up-for-week-2).
