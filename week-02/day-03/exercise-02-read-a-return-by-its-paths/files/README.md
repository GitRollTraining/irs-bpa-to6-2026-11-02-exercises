# A sample return, read by its paths

`returns/sample-return.xml` is a tax return written as XML, in the parts the IRS Modernized e-File
system uses: a `ReturnHeader`, then `ReturnData` with the Form 1040 inside. The course made up the
file and every value in it. `paths.csv` holds three of its Form 1040 fields: for each, the path to
it and its label.
