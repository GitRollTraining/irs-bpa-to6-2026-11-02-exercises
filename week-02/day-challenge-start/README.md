# Record your sessions, then open challenge 1

Two exercises, one notebook each, for the day you start challenge 1. Do them in order. Exercise 1 turns on Entire, which records your Codex sessions and links each one to your commit. Challenge 1 asks for that record with your work.

Open an exercise's `exercise.ipynb`, choose the **.venv** kernel, and run its first code cell to write the practice files. Then follow the steps in a terminal. An exercise is done when its last cell prints `Done:`.

| Exercise | What you will do |
|---|---|
| [1 · Codex sets up Entire](exercise-01-codex-sets-up-entire/exercise.ipynb) | Ask Codex to set up Entire, then check with Git that your commit is linked to the Codex session. |
| [2 · Codex explains the starter](exercise-02-codex-explains-the-starter/exercise.ipynb) | Let Codex read the challenge 1 starter, then name the task file, the inputs folder, and what you hand in. |

Both need Codex and the `entire` command. Solved copies are in [answers/](answers/).
