# Day 2: Git and GitHub in practice

Five exercises, one notebook each. You make your own copy of the challenge 1 starter on GitHub and hand in its link, get the course's new files with `git pull`, and then commit, push, branch and merge by hand. In the last one, Codex does the Git and you check it.

Open an exercise's `exercise.ipynb`, choose the **.venv** kernel, and run its cells from the top. Follow the steps in a terminal and in your browser. An exercise is done when its last cell prints `Done:`.

| Exercise | What you will do |
|---|---|
| [1 · Your own copy of the starter](exercise-01-your-own-starter-copy/exercise.ipynb) | Make your own public copy of the challenge 1 starter on GitHub, and hand in its link in the challenge 1 assignment. |
| [2 · Pull the new files](exercise-02-pull-the-new-files/exercise.ipynb) | Get the course team's newest commit with `git pull`, also after you changed a file it changes. |
| [3 · Commit and push](exercise-03-commit-and-push/exercise.ipynb) | Clone your copy, change `README.md`, commit, push, and find the commit on github.com. |
| [4 · Branch, pull request, merge](exercise-04-branch-pull-request-merge/exercise.ipynb) | Commit on a branch, open a pull request into your own `main`, merge it, and pull `main`. |
| [5 · Let Codex do the Git](exercise-05-codex-does-the-git/exercise.ipynb) | Have Codex commit and push one change, and check its work with `git log` and on github.com. |

Exercises 3 to 5 use the copy you make in exercise 1. Exercise 2 needs no GitHub account. Solved copies are in [answers/](answers/).
