# Day 1: Coding agents in practice

Six exercises, one notebook each. In each one you give a real task to Codex, the coding agent in your terminal, and then you check what it did. Each notebook writes its own practice files, so you can do the exercises in any order.

Open an exercise's `exercise.ipynb`, choose the **.venv** kernel, and run its first code cell to write the practice files. Then follow the steps in a terminal. An exercise is done when its last cell prints `Done:`.

| Exercise | What you will do | Slides |
|---|---|---|
| [1 · Give the error to Codex](exercise-01-error-to-codex/exercise.ipynb) | Let Codex run a script that fails, read the error and fix it. Keep the fix only if the total is right. | none yet |
| [2 · Write your own AGENTS.md](exercise-02-write-your-agents-md/exercise.ipynb) | Write rules for Codex, one of which leaves a file, and find that file after a task. | none yet |
| [3 · One request to one JSON record](exercise-03-one-record-to-json/exercise.ipynb) | Have Codex turn one request from challenge 1 into a record that the challenge's schema accepts. | none yet |
| [4 · Install a skill](exercise-04-install-a-skill/exercise.ipynb) | Install one popular skill with `npx skills add`, and compare Codex's work with and without it. | none yet |
| [5 · Keep it on disk](exercise-05-handoff-to-disk/exercise.ipynb) | Have Codex write `HANDOFF.md`, then let a new session finish the task from that file alone. | none yet |
| [6 · Install a skills plugin](exercise-06-install-a-plugin/exercise.ipynb) | Add a plugin that brings a set of skills, and run its setup skill in a practice project. | none yet |

Before exercise 1, Codex must be installed and signed in (course README, step 1). Exercise 4 also needs Node.js. Solved copies are in [answers/](answers/): each is the same notebook, and its first cell writes the finished files.
