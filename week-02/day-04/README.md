# Day 4: A return's XML

Three exercises, one notebook each. You read a return's XML file by its paths, write a reader's tests before the reader exists, and then have Codex write the reader to your tests. Each notebook writes its own practice files, and every value in them is made up.

Open an exercise's `exercise.ipynb`, choose the **.venv** kernel, and run its first code cell to write the practice files. Then follow the steps in a terminal. An exercise is done when its last cell prints `Done:`.

| Exercise | What you will do |
|---|---|
| [1 · Paths in a return](exercise-01-paths-in-a-return/exercise.ipynb) | Ask Codex for a return's element tree, then write the path to each value and mark what is missing or repeats in three returns. |
| [2 · Fixtures and tests first](exercise-02-fixtures-and-tests-first/exercise.ipynb) | Write three bad-input files and their tests before the reader exists, and see each wrong reader fail a test. |
| [3 · Codex writes the reader](exercise-03-codex-writes-the-reader/exercise.ipynb) | Find the faults in Codex's first reader with your tests, then have Codex fix it without changing a test. |

Do exercise 2 before exercise 3. After these, start challenge 1 with the two exercises in [day-challenge-start](../day-challenge-start/README.md). Solved copies are in [answers/](answers/).
