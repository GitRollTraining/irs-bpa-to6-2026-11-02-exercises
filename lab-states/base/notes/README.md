# The lab's simulated case notes

41 short notes, one per file, named by their number: `0101.txt` to `0140.txt`, and `0147.txt`, the
note the chapter uses as its example. Each is written for the course in the shape a person working a
compliance case writes as they go: which return it concerns, which tax year, what looked wrong, what
amount is in question if there is one, and what happens next.

"Synthetic filer" stands where a name would be. No note describes a real person or return, and none
is copied from a real case. 16 of the notes name no amount.
