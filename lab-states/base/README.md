# The case-notes extractor

The week's lab repository: a small Python function that reads one simulated case note and returns
its fields as JSON that a later program can rely on, and a way to find out how often it is right.

| Path | What it holds |
|---|---|
| `notes/` | the lab's simulated case notes, one per file; `notes/README.md` says what they are |
| `docs/fields.md` | the five fields the extractor returns, and the rule for each |
| `model.py`, `model-route.json` | the route to the model the extractor calls, supplied by the course team; not edited in the lab |

Everything in this repository is made up for the course. No note describes a real person or return.
