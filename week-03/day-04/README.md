# Week 3, day 4: reach Databricks from the Workstation's terminal

Three exercises, in order. Each runs in your Google Workstation's terminal, in your course folder: run `git pull` first, then go into the exercise's folder. You use the Databricks CLI, and in exercise 3 Codex. Each exercise uses the profile you save in exercise 1. Exercise 2 runs Wednesday's notebook. Exercise 3 reads the tables it writes. The course made up every row. The trainer prepares the day with [`../setup/day-04-setup.md`](../setup/day-04-setup.md).
