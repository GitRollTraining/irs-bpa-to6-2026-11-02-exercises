# Week 3, day 1: find the data a case-selection model needs, in Databricks

Four exercises, in order. Each runs in the class's Databricks workspace: open your Git folder of the course, pull, and open the exercise's notebook from it. Exercise 3 searches for items of the list you write in exercise 2. Monday's return table is `course.returns.return_header`. The course made up every row. The trainer sets the tables up first with [`../setup/day-01-setup.md`](../setup/day-01-setup.md).

1. [Tour the workspace: one table, two counts](exercise-01-tour-the-workspace/README.md). What you do: find a table in Catalog Explorer by its full name and count its rows in a notebook and the SQL editor. Where you work: Catalog Explorer, the SQL editor and the notebook `exercise-01-tour-the-workspace/exercise.ipynb`. Done when: cell 4 prints `Done:`, with the full name and the row count. [Start](exercise-01-tour-the-workspace/) · [Answer](answers/exercise-01-tour-the-workspace/)
2. [Your question, its data, each verdict](exercise-02-your-question-and-its-data/README.md). What you do: write a case-selection question and give each piece of information it needs a verdict and a reason. Where you work: the notebook `exercise-02-your-question-and-its-data/exercise.ipynb`, as thinking work. Done when: cell 4 prints `Done:`. [Start](exercise-02-your-question-and-its-data/) · [Answer](answers/exercise-02-your-question-and-its-data/)
3. [Find two of your items and check two drafts](exercise-03-find-and-check-two-drafts/README.md). What you do: find a column in the catalog by searching and check an AI-drafted column comment against the column's facts. Where you work: Catalog Explorer and the notebook `exercise-03-find-and-check-two-drafts/exercise.ipynb`. Done when: cell 4 prints `Done:`, with two entries, each with its check. [Start](exercise-03-find-and-check-two-drafts/) · [Answer](answers/exercise-03-find-and-check-two-drafts/)
4. [Trace one column to its source](exercise-04-trace-one-column/README.md). What you do: trace one column of a derived table to its source columns in the Lineage tab and say where the trace stops. Where you work: Catalog Explorer's Lineage tab and the notebook `exercise-04-trace-one-column/exercise.ipynb`. Done when: cell 3 prints `Done:`.
