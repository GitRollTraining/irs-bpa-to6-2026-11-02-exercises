# Week 3, day 2: test the batch, keep only what the use needs, and check Genie's answers, in Databricks

Five exercises, in order. Each runs in the class's Databricks workspace: open your Git folder of the course, pull, and open the exercise's notebook from it. Exercises 1 and 2 start from your notebooks of Monday's exercises 3 and 2. Tuesday's batches are `course.returns.batch_clean`, `course.returns.batch_dirty` and `course.returns.batch_governed`. The course made up every row. The trainer sets the batches and the Genie Agent up first with [`../setup/day-02-setup.md`](../setup/day-02-setup.md).

1. [Tests that fail the dirty batch](exercise-01-tests-that-fail-the-dirty-batch/README.md). What you do: write data tests that fail a dirty batch, and name each test's kind and action. Where you work: the notebook `exercise-01-tests-that-fail-the-dirty-batch/exercise.ipynb`. Done when: cell 5 prints `Done:`, with four tests that pass the clean batch. [Start](exercise-01-tests-that-fail-the-dirty-batch/) · [Answer](answers/exercise-01-tests-that-fail-the-dirty-batch/)

What you do: record each field's need, class and action, and prepare the batch so no field that names a person survives. Where you work: the notebook `exercise-02-field-record-and-case-key/exercise.ipynb`. Done when: cell 4 prints `Done:`, with every field recorded. [Start](exercise-02-field-record-and-case-key/) · [Answer](answers/exercise-02-field-record-and-case-key/)
