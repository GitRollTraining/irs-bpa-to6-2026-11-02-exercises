# Week 3, day 3: from parsed returns to features and leak-free sets

Four exercises, in order. Each runs in the class's Databricks workspace: open your Git folder of the course, pull, and open the exercise's notebook from it. Each exercise starts from the tables the one before it wrote in your schema, `course.learner_NN`. The return files are in the volume `/Volumes/course/returns/raw/`. The course made up every file. The trainer sets them up first with [`../setup/day-03-setup.md`](../setup/day-03-setup.md).

1. [Write the keyed tables and test their counts](exercise-01-keyed-tables/README.md). What you do: write the return files into three keyed tables, and test that their counts match the files. Where you work: the notebook `exercise-01-keyed-tables/exercise.ipynb`. Done when: cell 7 prints `Done:`, with `return_table`, `dependents` and `w2s` in your schema. [Start](exercise-01-keyed-tables/) · [Answer](answers/exercise-01-keyed-tables/)
2. [Build the features table with a ratio across two tables](exercise-02-features-and-a-ratio/README.md). What you do: add a ratio that reads two tables to the features table, and keep one row for each return. Where you work: the notebook `exercise-02-features-and-a-ratio/exercise.ipynb`. Done when: cell 6 prints `Done:`, with `features` and `feature_record` in your schema. [Start](exercise-02-features-and-a-ratio/) · [Answer](answers/exercise-02-features-and-a-ratio/)
3. [Add the history and the change since last year](exercise-03-history-and-change/README.md). What you do: add a filer's mean of earlier wages and the change since last year, from earlier years only. Where you work: the notebook `exercise-03-history-and-change/exercise.ipynb`. Done when: cell 8 prints `Done:`. [Start](exercise-03-history-and-change/) · [Answer](answers/exercise-03-history-and-change/)
4. [Mark what the selection day knows, then split by year](exercise-04-selection-day-and-split/README.md). What you do: mark each feature known on the selection day or not, and split the features by tax year without leakage. Where you work: the notebook `exercise-04-selection-day-and-split/exercise.ipynb`. Done when: cell 7 prints `Done:`, with `train`, `valid` and `test` in your schema. [Start](exercise-04-selection-day-and-split/) · [Answer](answers/exercise-04-selection-day-and-split/)

[`wednesday-tables.ipynb`](wednesday-tables.ipynb) runs your four exercise notebooks in order and lists your eight tables. On Thursday you run it as a job, from the Workstation.
