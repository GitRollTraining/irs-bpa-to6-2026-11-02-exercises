# The data-rules check

Taken before any AI tool touches this repository. Each row is one item of information and one tool.
In Permitted?, write Yes, No, or Not mine to decide. In Why, write the reason in a sentence; in every
row that is not Yes, end it with the chapter section whose rule it rests on, such as (section 1.1).

| Information | Tool | Permitted? | Why |
|---|---|---|---|
| A simulated note from the lab repository | The approved coding tool, in the course's hosted environment | Yes | The notes are written for the course and describe no real person, and the tool is approved for the course |
| A real case note from your own work | A public chat tool | No | The AI policy prohibits putting taxpayer information into any public, non-Treasury or otherwise unauthorized AI system (section 1.1) |
| The same real note with the name and identification number removed | A public chat tool | No | Removing a name does not show the note can no longer be associated with a taxpayer, and the prohibition also covers any other non-public record (section 1.1) |
| Your own code, with no taxpayer data in it | A public chat tool | No | Only Treasury- or IRS-approved tools may be used, and the policy warns that even harmless-looking work matters carry risk in public tools (section 1.3, section 1.1) |
| A real case note | An approved tool, for work that tool has not been approved for | Not mine to decide | Each use must be approved by an accountable agency official, not by the developer (section 1.3) |
| The agent's session log from the lab | Attached to your pull request as evidence | Yes | It holds only simulated data, and keeping it is part of the record |
