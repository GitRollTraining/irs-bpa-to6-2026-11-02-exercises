# Codex CLI: a hands-on start

Three exercises that teach you to drive Codex, the coding agent that runs in your terminal. Codex is already installed and signed in on your workstation. Each notebook explains one part of Codex, then you try it in the terminal on a small practice project that the notebook writes for you.

Open an exercise's `exercise.ipynb`, choose the **.venv** kernel, and run its first code cell to write the practice files. Then follow the steps in a terminal. An exercise is done when its last cell prints `Done:`.

| Exercise | What you will do | Time |
|---|---|---|
| [1 · Meet Codex](exercise-01-first-codex-session/exercise.ipynb) | Start Codex so it can only read, look around its screen, ask it two questions about some code, and leave. | 20 min |
| [2 · Approve one fix](exercise-02-approve-one-fix/exercise.ipynb) | Let Codex make one fix only after you read it, then check the fix with `/diff`, the tests and Git. | 25 min |
| [3 · Guide Codex](exercise-03-guide-codex/exercise.ipynb) | Give Codex standing rules in `AGENTS.md`, come back to a chat with `codex resume`, and run one task with `codex exec`. | 30 min |

These exercises follow the official [Codex CLI documentation](https://learn.chatgpt.com/docs/codex/cli). Solved copies are in [answers/](answers/).
