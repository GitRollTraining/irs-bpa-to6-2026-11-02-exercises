# Day 3: Forms, tools and a score

Three exercises, one notebook each. Each one practises one idea from the Day 3 slides on the same made-up online shop: a program sends customer messages to an AI model and gets four fields back as JSON. The model's replies are sample data inside each notebook, so you need no model, key or sign-in.

Open an exercise's `exercise.ipynb`, choose the **.venv** kernel, and run the cells from the top. An exercise is done when its last cell prints `Done:`.

| Exercise | What you will do | Slides | Time |
|---|---|---|---|
| [1 · Check every reply against a schema](exercise-01-validate-replies/exercise.ipynb) | Sort model replies into passes and failures, fixing none. | 4, 5, 7 | 25 min |
| [2 · Define a safe function](exercise-02-define-a-safe-function/exercise.ipynb) | Fix a model's function list, and check every call it asks for. | 13, 14, 16 | 30 min |
| [3 · Score a prompt](exercise-03-score-a-prompt/exercise.ipynb) | Score two versions of a prompt field by field, and keep the better one. | 22, 23, 24, 27 | 20 min |

Solved copies are in [answers/](answers/): each is the same notebook with the solution filled in.
