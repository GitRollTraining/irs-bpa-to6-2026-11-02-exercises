`start.py` builds `extractor/` from these files. Do not edit the files here. Edit the copies in `extractor/`.

- `evaluation/` holds the labelled set, the scorer and the write-up for one failure.
- `teammate-system.txt` is the prompt that the teammate commits as `prompts/system.txt`.
- `first-run/` holds the replies of the first run of the set on that prompt, as `model.py` returned them. The course team made this run on 2026-11-03, outside the hosted workspace: route `codex`, model `gpt-6-luna` at the level `low`, Codex CLI 0.165.0-alpha.1.2.
