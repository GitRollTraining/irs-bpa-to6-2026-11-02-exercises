# Codex practice

Practice with Codex, OpenAI's coding agent, in your workstation terminal, apart from the day folders and their case: each exercise sits in its own folder with everything it uses, and its worked answer is under `answers/`. [Direct Codex through one change](direct-one-change/README.md) has Codex add one feature with a test to a small Python project; you review the change with `/diff` and commit it.
